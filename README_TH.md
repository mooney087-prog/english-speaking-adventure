# English Speaking Adventure — คู่มือนำขึ้น Netlify

แอปฝึกพูดภาษาอังกฤษ ป.3 ของ Wongduen Khunakon, English teacher

## ในชุดไฟล์นี้

- 5 ด่าน: Fruits, School Things, Animals, Food and Drinks, School Places
- ด่านละ 10 คำศัพท์ + 5 ประโยค รวม 50 คำศัพท์และ 25 ประโยค พร้อมคำอ่านไทยโดยประมาณและคำแปล
- ภาพเหมือนจริง, ภาพนำเข้าด่าน, มาสคอตสุนัขจิ้งจอก, คะแนนความพยายาม, เกียรติบัตร
- ฝึกฟังครบ 10 คำ → อัดเสียงครบ 10 คำ → ฟังและอัดเสียง 5 ประโยค → เปิดด่านถัดไป
- หลังบ้านสำหรับครู: สร้างรหัสนักเรียน, ดูการเข้าเรียนล่าสุด, ดูความก้าวหน้ารายด่าน, ฟังเสียงครั้งแรกและครั้งล่าสุด

**ชุดนี้เป็นซอร์สโค้ดพร้อมนำไปติดตั้ง ยังไม่ได้เชื่อมบัญชี Netlify/Supabase ของครู และยังไม่มีลิงก์สำหรับแจกนักเรียน**

## 1. เตรียมหลังบ้าน Supabase

1. สร้างโปรเจกต์ของครูที่ https://supabase.com/dashboard
2. ไป SQL Editor เปิดไฟล์ `setup/database.sql` คัดลอกทั้งหมดไปรันหนึ่งครั้งในโปรเจกต์ใหม่
3. SQL จะสร้างตารางและพื้นที่เสียงแบบ private ชื่อ `speaking-audio`
4. เก็บ Project URL และ Secret API key สำหรับเซิร์ฟเวอร์ (ขึ้นต้น `sb_secret_`) จาก Project settings / API keys ไว้ตั้งค่าใน Netlify เท่านั้น แอปรองรับ legacy service_role key หากบัญชียังใช้ระบบเดิม
5. เปิด Data API สำหรับ public schema ในโปรเจกต์ตามปกติ ตารางมี RLS และให้สิทธิ์เฉพาะ service_role ผ่านเซิร์ฟเวอร์ ไม่ต้องเพิ่มนโยบายให้บุคคลทั่วไป

ห้ามใส่ secret key ใน `public/`, GitHub, ภาพหน้าจอ หรือส่งให้นักเรียน

## 2. นำโค้ดขึ้น Netlify

### วิธีแนะนำ: เชื่อม Git repository

1. แตก ZIP แล้วนำไฟล์ภายในโฟลเดอร์ `english-speaking-adventure` ขึ้น repository ใหม่ของครู โดยให้ `package.json` และ `netlify.toml` อยู่ที่ราก repository
2. ที่ Netlify เลือก Import an existing project แล้วเชื่อม repository ดังกล่าว
3. ตั้ง Base directory ว่าง, Build command `npm run check`, Publish directory `public` และ Node.js 22 ขึ้นไป
4. ใช้ Functions directory `netlify/functions` ตาม `netlify.toml` ที่จัดไว้
5. เพิ่ม Environment variables 4 รายการด้านล่าง ผ่านหน้า Netlify และให้มีขอบเขต Functions/Runtime ของ production (หรือ All scopes)

| ตัวแปร | ค่าที่ใส่ |
|---|---|
| `SUPABASE_URL` | Project URL ของ Supabase |
| `SUPABASE_SECRET_KEY` | Secret API key ฝั่งเซิร์ฟเวอร์ของ Supabase |
| `TEACHER_PASSWORD` | รหัสครูแบบสุ่มอย่างน้อย 16 ตัวอักษร |
| `SESSION_SECRET` | ค่าสุ่มลับอย่างน้อย 32 ตัวอักษร |

6. Deploy หรือ Redeploy หลังเพิ่ม/เปลี่ยนตัวแปร อย่าใส่ตัวแปรลับลง `netlify.toml`
7. เปิดลิงก์ HTTPS ที่ Netlify ให้มา เข้าลิงก์ Teacher dashboard ด้านล่าง แล้วลงชื่อเข้าด้วย `TEACHER_PASSWORD`

ครูที่ใช้คอมพิวเตอร์และมี Node.js สามารถสร้างค่าสุ่มโดยรัน `node setup/generate-secrets.mjs` ในเครื่องตนเอง แล้วเก็บผลลัพธ์เป็นความลับ

### ถ้าเคยใช้การลากโฟลเดอร์วางใน Netlify

การลากเฉพาะ `public/` วางทำให้ดูตัวอย่างหน้าฝึกได้ แต่ยังใช้งานบัญชีนักเรียน เก็บเสียง ตรวจงาน หรือออกเกียรติบัตรจริงไม่ได้ เพราะต้อง deploy Functions ด้วย ให้ใช้วิธี Git ด้านบนสำหรับแอปฉบับเต็ม

## 3. เตรียมรหัสนักเรียน

1. ที่หน้า Teacher dashboard เพิ่มนักเรียนทีละคน ใส่รหัส เช่น P301, ชื่อ–นามสกุล และชื่อเล่น
2. ระบบจะสร้างรหัสเข้าเรียน (PIN) แบบสุ่มให้ จดทันที เพราะแสดงเพียงครั้งเดียว
3. ส่งลิงก์แอปและรหัสของแต่ละคนให้ผู้ปกครองเป็นรายบุคคล ไม่ใช้รหัสร่วมกันทั้งห้อง
4. ก่อนฝึก นักเรียนใส่รหัสนักเรียน, PIN, ชื่อ–นามสกุลสำหรับเกียรติบัตร และชื่อเล่น ตรวจชื่อก่อนเริ่ม
5. ในรุ่นนี้การกู้ PIN ทำโดยครูที่จัดการ Supabase หรือสร้างรหัสนักเรียนใหม่ ยังไม่มีปุ่มรีเซ็ต PIN ในหน้าเว็บ

## 4. การฝึกและคะแนน

- กด Listen ฟังจนจบ จึงกด Next ได้ นักเรียนไม่ต้องแข่งเวลา
- เมื่อฟังครบ 10 คำ จะเข้าส่วนอัดเสียงทีละคำ รูปและคำศัพท์จะปรากฏพร้อมกัน
- กด Record my voice → อนุญาตไมโครโฟน → พูด → Stop recording → ฟังเสียงตนเอง → Use this recording
- อัดได้ครั้งละไม่เกิน 20 วินาที / 2 MB อัดใหม่ได้ก่อนเลือกบันทึก
- ส่วนประโยคต้องฟังต้นแบบก่อน จึงเปิดปุ่มอัดเสียง
- คะแนนด่านละ 30: ฟังคำศัพท์ 10 + บันทึกคำศัพท์ 10 + ฟังประโยค 5 + บันทึกประโยค 5 รวม 150 คะแนน
- คะแนนแสดงความสำเร็จของกิจกรรม ไม่ใช่คะแนนความถูกต้องในการออกเสียง ไม่มี AI ตรวจสำเนียงหรือวิเคราะห์เสียงเงียบ ครูฟังและให้คำแนะนำจากหลังบ้าน
- เมื่อจบด่าน มาสคอตจะเต้น กด Play celebration beat เพื่อฟังเพลงสั้นต้นฉบับพร้อมเสียงปรบมือสังเคราะห์ หรือข้ามได้
- เพลงในรุ่นนี้ยังไม่ใช่เพลง “67” เพราะยังไม่มีไฟล์เพลงที่ครูเลือกไว้

## 5. เกียรติบัตรอัตโนมัติ

เมื่อนักเรียนทำครบ 5 ด่าน และส่งงานครบทุกกิจกรรม ระบบตรวจผลจากเซิร์ฟเวอร์และแสดงเกียรติบัตรหลัง Continue adventure ครั้งสุดท้าย หรือกด My certificate บนแผนที่

ใช้ชื่อ–นามสกุลที่นักเรียนกรอก พร้อมวันที่สำเร็จ ลายเซ็นตัวอย่าง Wongduen Khunakon, ชื่อพิมพ์ Wongduen Khunakon และตำแหน่ง English teacher

กด Save as PDF / Print แล้วเลือก Save as PDF ในหน้าพิมพ์ของเบราว์เซอร์ เกียรติบัตรจัด A4 แนวนอน ชื่อภาษาไทยใช้ฟอนต์ของอุปกรณ์ หากต้องแก้ชื่อ ให้ออกจากระบบและเข้าใหม่ด้วยรหัสเดิมแล้วกรอกชื่อที่ถูกต้อง

## 6. สิ่งที่ครูดูได้

- รายชื่อและเวลาเข้าเรียนล่าสุด (เวลาล็อกอิน ไม่ใช่สถานะออนไลน์สด)
- จำนวนการฟัง คำศัพท์ที่อัด และประโยคที่อัด แยกทุกด่าน
- เสียงครั้งแรกและครั้งล่าสุดของแต่ละคำ/ประโยค เพื่อเปรียบเทียบพัฒนาการ
- เวลาเรียนจบและเวลาออกเกียรติบัตร

ลิงก์เสียงเป็นลิงก์ชั่วคราวสำหรับครู เมื่อหมดอายุให้กดฟังใหม่ ระบบเก็บไฟล์เสียงที่ส่งทั้งหมด แต่หน้าแสดงทางลัดครั้งแรก/ล่าสุด ครูควรกำหนดระยะเวลาเก็บข้อมูลและตรวจพื้นที่ใช้งานของบัญชี

## 7. มือถือ เสียง และอินเทอร์เน็ต

- เปิดลิงก์ HTTPS ใน Chrome หรือ Safari โดยตรง แทนเบราว์เซอร์ภายในแอปแชต
- ออกแบบแนวตั้ง ตรวจการแสดงผลที่ความกว้าง 320, 360 และ 390 px ภาพคำศัพท์เป็นกรอบสี่เหลี่ยม ไม่ยืด ไม่ขยายล้นจอ
- ปุ่มคำอ่านและคำแปลกดเปิดได้ เพื่อให้หน้าจอไม่แน่นเกินไป
- เสียงต้นแบบใช้ระบบอ่านออกเสียงภาษาอังกฤษของอุปกรณ์ โดยเลือก British English เมื่อมี ไม่ใช่ไฟล์เสียงคนเจ้าของภาษาที่บันทึกไว้ เสียงและคุณภาพจึงต่างตามเครื่อง ต้องเปิดเสียง/ติดตั้งเสียงภาษาอังกฤษในเครื่อง
- หากเสียงต้นแบบเล่นไม่สำเร็จ ระบบไม่ข้ามนับว่าฟังแล้ว กรุณาตรวจการตั้งค่าเสียงของมือถือ
- หากเน็ตหลุดระหว่างฝึก ไฟล์ที่เลือกบันทึกจะเข้าคิวในเบราว์เซอร์ ส่งเมื่อออนไลน์หรือกดส่งงานที่รอส่ง ห้ามล้างข้อมูลเบราว์เซอร์/ใช้โหมดไม่ระบุตัวตนก่อนส่งครบ
- รุ่นนี้ไม่ได้เก็บหน้าเว็บทั้งแอปสำหรับเริ่มเปิดแบบออฟไลน์ ต้องมีเน็ตตอนเปิดแอปและเข้าระบบ
- หลีกเลี่ยงใช้บัญชีหลายคนสลับกันขณะมีงานรอส่ง งานที่รอจะส่งเมื่อเจ้าของบัญชีนั้นเข้าระบบ

## 8. ทดลองก่อนแจกนักเรียน

1. สร้างนักเรียนทดสอบในหลังบ้าน
2. ใช้มือถือจริงฟัง 10 คำ อัด 10 คำ และฝึก 5 ประโยคในด่านแรก
3. ตรวจว่าเสียงปรากฏใน Teacher dashboard และลองอัดใหม่เพื่อเทียบครั้งแรก/ล่าสุด
4. ทดสอบตัดเน็ตหลังโหลดหน้า เลือกเสียงบันทึก แล้วเปิดเน็ตและกดส่งงาน
5. ทดลองจนครบ 5 ด่านด้วยบัญชีทดสอบ ตรวจชื่อและบันทึก PDF เกียรติบัตร
6. หลังผ่านขั้นตอนนี้จึงแจกนักเรียนจริง

ตรวจโค้ดและกติกาคะแนนด้วย `npm run check` ได้ โค้ดหลังบ้านและกติกาคะแนนมีการทดสอบแบบจำลอง แต่ยังไม่ได้ทดสอบเชื่อม Supabase จริงในบัญชีครู หรือไมโครโฟนบนโทรศัพท์จริง สภาพแวดล้อมตัวอย่างไม่มีเสียงอ่านอังกฤษที่ใช้งานได้ จึงยังยืนยันการเล่นเสียงบนมือถือจริงไม่ได้

## โครงสร้างสำหรับแก้ไขต่อ

| ไฟล์ | หน้าที่ |
|---|---|
| `public/content.js` | คำศัพท์ ประโยค คำอ่านและคำแปล |
| `public/app.js`, `public/style.css` | หน้านักเรียนและเกียรติบัตร |
| `public/teacher.html`, `public/teacher.js` | หลังบ้านครู |
| `public/store.js` | คิวบันทึกเสียงในเครื่องและการเรียก API |
| `public/assets/` | ภาพทุกด่าน ภาพคำศัพท์ มาสคอต และลายเซ็น |
| `netlify/functions/api.mjs` | API สำหรับบัญชี ส่งเสียงและออกเกียรติบัตร |
| `setup/database.sql` | ตั้งค่าฐานข้อมูลและพื้นที่เสียง |

ภาพคำศัพท์เป็นแผ่น 5 คอลัมน์ × 2 แถว หากเปลี่ยนภาพให้รักษาลำดับคำใน content.js และอัตราส่วน 5:2 ของแผ่นภาพ
